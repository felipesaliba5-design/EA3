Ambiente de Orquestração: n8n Workflow Automation Platform (v1+)
Tecnologias Integradas:
  • Motor de Agentes e Orquestração: n8n, LangChain Agent v2, Buffer Memory Window
  • Modelos de IA (OpenAI): gpt-4o-mini (Raciocínio/Chat) e text-embedding-3-small (Embeddings)
  • Banco de Dados Vetorial: Supabase (PostgreSQL 15+ com extensão pgvector e índice HNSW)
  • Protocolo de Comunicação: HTTP REST via Webhook do n8n com suporte total a CORS
  • Aplicação Consumidora: Interface Web Interativa (HTML5, CSS3 e JavaScript puro - index.html)

3. VISÃO GERAL, EVOLUÇÃO E AJUSTES REALIZADOS
--------------------------------------------------------------------------------
1. COMPORTAMENTO E DIRETRIZES DO AGENTE (PERSONA EDUBOT):
   - Triagem Obrigatória: Se o aluno faz pergunta sobre prazos mas não especifica o curso (React ou Node.js), o EduBot pergunta o curso antes de qualquer busca.
   - Bloqueio de Dúvidas de Código e Avaliações: NUNCA responde código ou dá dicas para avaliações do curso; orienta o aluno a agendar mentoria 1:1 pelo portal.
   - Bloqueio de Prorrogação de Prazos: Aplicação estrita e empática da política de não prorrogação para assegurar a isonomia.
   - Escalonamento Exclusivo para TI: Acionamento exclusivo para bugs da plataforma (Erro 500, tela branca), com coleta de e-mail.

2. BASE DE CONHECIMENTO DINÂMICA (RAG COM SUPABASE PGVECTOR):
   - Correção na descrição da Tool no n8n: declara expressamente a base oficial da DevAcademy.
   - 20 documentos oficiais ingeridos com chunking de 1000 caracteres e embeddings OpenAI.

3. COMUNICAÇÃO HTTP POR WEBHOOK (BACKEND DESACOPLADO):
   - Payload de entrada: { "message": "...", "session_id": "..." }
   - Suporte universal a CORS (Access-Control-Allow-Origin: *).
   - Sessões gerenciadas via session_id.


4. CASOS DE USO VALIDADOS
--------------------------------------------------------------------------------
• Caso 1: Consulta de Prazos (Bootcamp React) -> Retorna 05/12/2026 às 23:59 via RAG imediato.
• Caso 2: Pergunta Incompleta -> Pergunta qual o curso antes de buscar.
• Caso 3: Dúvida de Código de Avaliação -> Recusa responder e indica mentoria individual.
• Caso 4: Solicitação de Extensão de Prazo -> Nega conforme a política de prazos.
• Caso 5: Bug de Sistema / Erro 500 -> Coleta e-mail e encaminha para suporte de TI.
• Caso 6: Memória Conversacional -> Mantém o contexto pelo session_id.


5. INSTRUÇÕES PARA EXECUÇÃO
--------------------------------------------------------------------------------
1. No n8n: Importe o arquivo 'workflow_edubot.json'.
2. Conecte as credenciais (OpenAI, Supabase, GitHub).
3. Ative o workflow (Active = ON).
4. Abra o arquivo 'index.html' no navegador com duplo-clique.
5. Converse normalmente com o EduBot!
